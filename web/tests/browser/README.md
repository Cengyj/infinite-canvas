# 本地功能隔离验收

这些页面只允许在 `http://127.0.0.1:3001` 打开，使用该独立 origin 的浏览器存储。不要在日常使用的 3000 端口运行，也不要关闭用户已有页面。页面通过 CSP 阻止外网连接；视频页面以 Axios adapter 返回本地合成视频，提示词页面拦截 fetch 返回受控 Responses 流。没有真实模型请求、计费或真实生成质量验证。

在 web 目录运行 `bun run dev --host 127.0.0.1 --port 3001 --strictPort`，使用独立标签打开下方入口。这仅启动开发服务，不执行构建、类型或语法检查。控制栏为测试夹具，产品页面不增加这些按钮。

## 提示词优化

入口：`/tests/browser/prompt-optimizer.html`。挂载实际 `usePromptOptimizer`、统一弹窗与 `InfiniteCanvas`，保留 StrictMode、主题和本地收藏存储。控制栏提供延迟片段、完整终态、失败和 EOF；模拟接口故意允许取消后返回，供检查迟到响应。下列是复现步骤，执行结果以待测试文档为准，不代表真实模型质量。

1. 点「切换空草稿」再打开优化弹窗：不发请求，补充草稿后才可开始；核对开始/重新优化、继续、应用位于同一底部操作行，并检查窄屏滚动及明暗主题。
2. 在补充要求保留已有文字，打开「常用要求」追加建议并重复选择：不得替换原文或重复追加同一完整要求。收藏、重开/刷新、切换图片/视频及删除，核对只保存明确收藏的要求，场景不混用。
3. 开始后「发送片段」：结果仅预览、不可应用；点「完成」后才就绪。清空结果应显示暂不可应用；另用含 token 草稿删除一个必需 token，检查就绪勾选消失且应用禁用。
4. 源稿 A 完成得到 A1 后，手改左侧为 B：「基于结果继续」和「应用到提示词」均禁用，重新优化实际发送 B；失败或停止后应保留 B 与 A1。恢复为 A 时恢复资格；手改结果为 A1′ 后，下一轮继续必须发送 A1′。
5. 有完整结果后只修改补充要求或有效文本模型：继续可用，应用旧结果禁用；诊断中的 source 应为此前完整结果、requirements/model 为新值。继续失败或不完整 EOF 后恢复此前源稿和完整结果，完成并应用只回填当前提示词。点击「精简表达，不扩写」，核对实际 requirements 明确禁止扩写、增加视觉细节和动作，而不只是预设标签如此。
6. 优化中停止、关闭或卸载编辑器，再在「响应目标」选中旧请求并释放迟到响应：不得覆盖新会话或增加应用次数。新请求仍可独立完成。
7. 优化中改变外部来源或外部切换文本模型：取消标记更新，旧结果不可应用；重新读取后使用新来源。
8. 在源稿、补充要求、结果、弹窗按钮和常用要求浮层内按 Space/Control：画布工具/光标不应切换，文字空格及按钮键盘激活正常。关闭弹窗后，在画布按住/松开 Space/Control 应仍临时切换并恢复工具；普通工具栏按钮按 Space 不应重复点击。

控制栏的请求诊断包含场景、原稿、要求与取消状态，不包含密钥。此页不覆盖真实画布组拓扑或模型画质；组内自身源图角色由针对性的行为测试和产品入口人工验收补充。

本轮在独立 3001 origin 使用真实组件与 StrictMode 验证了源稿 A/B 与旧完整结果的继续资格、失败/停止保留、恢复 A 和手改结果、修改要求/有效文本模型后的实际请求、EOF 恢复、精简预设的实际要求、取消后的迟到响应隔离以及单次确认回填。截图 `/tmp/infinite-canvas-prompt-review.png` 展示手改源稿后旧结果仍可查看、继续与应用均禁用；截图和所有返回正文均属于模拟交互证据。

此前一轮已使用真实组件及 localforage 验证空稿/流式/完整结果、无效编辑、要求追加去重、收藏重开/刷新/删除和场景隔离、失败/不完整 EOF/停止、迟到响应、来源/模型失效及单次回填。弹窗 Space 可启动且未被阻止，普通画布工具栏 Space 被阻止且未点击按钮，弹窗内 Control 不切换画布工具。键盘诊断在冒泡阶段收集，避免捕获阶段微任务早于画布处理而误报。明暗主题与 1280×720、1014×1224 布局、底部操作同排及控制台 error 列表为空均为此前观察，不代表本轮重复执行。

所有响应均为本地模拟，未请求真实模型或计费；窄手机视口、真实产品入口和组拓扑、实际浏览器存储故障仍待验收。存储错误仅有行为 mock 测试覆盖，不将其当作浏览器故障验证。

## 画布

入口：`/tests/browser/canvas-lifecycle.html`。挂载实际 `CanvasPage`，保留 StrictMode、Ant Design 主题和实际存储链路。顶部工具栏仅用于验收，不属于产品 UI。

1. 点「创建 A/B 隔离项目」。两个项目故意复用相同节点 ID，但使用不同提示词和远端任务 ID，便于检出跨项目回填。默认进入 A，并自动恢复其 pending 视频任务。
2. 在任务未完成时切换 B，再点「完成全部模拟视频」。B 应只收到绿色 B 视频；返回 A 后，A 应只收到蓝色 A 视频。读取快照时，两项目的提示词和任务 ID 不得互换。
3. 点「延迟下一次查询」，待「等待释放」出现 1，再切换项目或「离开项目」，然后释放旧查询。旧响应不得覆盖当前项目；当前请求应继续独立运行。
4. 完成视频后读取快照：内存项目和持久化项目均应持有对应 `storageKey`；稍后再次读取可观察项目现有延迟写入完成。错误诊断不得出现 `flushSync` 生命周期警告。
5. 点「刷新验收页」后应恢复同一路由与已保存结果。pending 任务会按保存的任务 ID 重建模拟查询，成功结果不应再下载。
6. 点「打开不存在项目」应跳回验收列表占位，不得把上个项目节点写入不存在的项目。点「下次查询失败」可检查失败提示、保留任务 ID以及后续重试。

请求、控制台错误和持久化快照可在工具栏的诊断区域读取。页面不清空整个数据库；再次创建会新增一对专用验收项目。

## 视频工作台

入口：`/tests/browser/video-lifecycle.html`。使用其顶部按钮验收工作台卸载、重挂载、迟到创建响应、查询失败和日志持久化。该页面同样只证明前端生命周期行为，不能证明模型支持边界或生成质量。

1. 开始任务后点产品的「新建」并输入另一条草稿，再完成模拟任务：旧记录成功，当前草稿和空结果保持。
2. 点「下次查询失败」后开始；失败卡片点「重试」，创建次数应不增加。
3. 开启延迟创建后开始任务，离开工作台、释放创建响应、完成模拟任务，再返回：保存并查询原 taskId，只下载一次。
4. 将成功结果加入我的资产，删除对应日志，读取快照：日志消失，但资产和其 media key 保留。删除 pending 日志后完成模拟任务：日志不得复活。
5. 先选 1080p，再通过实际上传按钮导入两张测试图。1080p 置灰但原值保留；开始生成时报错，创建计数不增加，两张参考图仍在。
6. 切换明暗主题核对原控件布局；诊断快照只用于检查本 origin 的测试记录。
