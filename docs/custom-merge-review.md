# 定制合并复核

本次以用户指定的 `infinite-canvas-main` 定制源码目录为来源，并以当前项目已经合入的 v0.17–v0.19 修复为基线逐文件复核。来源目录的 `VERSION` 仍为 v0.16.1，因此不能只按版本号判断差异。

## 已合入的定制能力

- 图片工作台、视频工作台和画布图片/视频节点新增「优化提示词」入口。优化请求使用当前选定的文本模型和渠道，发送来源提示词、参考图标签、可选视觉分析和生成上下文；结果流式显示，用户确认后才回填。
- 资产编辑、资产包导入、画布导入和 WebDAV 合并都保留临时媒体引用，导入文件重建本机 storage key 和 Blob URL，异步失败不会提前释放仍在写入的文件。
- Grok 视频使用独立 JSON 字段、1–15 秒、专用画幅和最多 7 张参考图；普通视频模型继续支持当前的首尾帧、多图、视频参考和音频参考参数。轮询统一为 3 秒间隔、20 分钟期限。
- 图片和视频结果保留真实比例及视频播放时长；生成耗时单独保存。画布批量图片支持子图独立预览、设为主图、重试和删除。
- 新增 OpenAI Sora 标准 `input_reference` 模板，同时保留原有扩展模板；已有用户脚本、渠道地址、API Key 和自定义请求参数不被模板升级覆盖。

## 与当前基线合并时的取舍

- 复用了当前媒体引用、缩略图、并发删除锁、代理 URL 和网络错误分类，没有恢复来源已经过时的单一图片 lease、Veo 单图/720p 限制或把所有网络错误统称为 CORS。
- 保留 GPT Image 的 `output_format`/背景参数分流、Gemini 图片 `imageConfig` 和 Base URL 查询参数；提示词优化显式使用 `store: false`，避免把中间结果写入远端响应存储。
- 本地存储读取失败时，Canvas/Asset store 会停止清理和持久化写入；跨标签页存在时自动清理保守跳过，避免坏读或另一标签页的未保存引用导致误删。
- 文本流只有收到 OpenAI/Gemini 完整终态才会回填；截断、拒绝、上游错误、取消和断流都会保留旧草稿并显示错误。

## 验证范围

`web/tests` 当前全量行为测试通过：82 项、338 条断言。覆盖提示词优化、Grok 与普通视频分流、Gemini/OpenAI 文本流终态、媒体解码和并发清理、渠道 URL/查询参数、代理诊断、资产同步清单及画布绑定。真实第三方生图/视频接口未在本次测试中调用，部署后的 API Key、模型权限和上游响应仍需按 `pending-test.mdx` 手工验收。
