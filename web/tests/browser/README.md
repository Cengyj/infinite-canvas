# 本地生命周期隔离验收

这些页面只允许在 `http://127.0.0.1:3001` 打开，使用该独立 origin 的浏览器存储。不要在日常使用的 3000 端口运行，也不要关闭用户已有页面。页面通过 CSP 阻止外网连接，并以 Axios adapter 返回本地合成视频；没有真实模型请求、计费或真实画质验证。

在 web 目录运行 `bun run dev --host 127.0.0.1 --port 3001 --strictPort`，使用独立标签打开下方入口。这仅启动开发服务，不执行构建、类型或语法检查。控制栏为测试夹具，产品页面不增加这些按钮。

## 画布

入口：`/tests/browser/canvas-lifecycle.html`。挂载实际 `CanvasPage`，保留 StrictMode、Ant Design 主题和实际存储链路。顶部工具栏仅用于验收，不属于产品 UI。

1. 点「创建 A/B 隔离项目」。两个项目故意复用相同节点 ID，但使用不同提示词和远端任务 ID，便于检出跨项目回填。默认进入 A，并自动恢复其 pending 视频任务。
2. 在任务未完成时切换 B，再点「完成全部模拟视频」。B 应只收到绿色 B 视频；返回 A 后，A 应只收到蓝色 A 视频。读取快照时，两项目的提示词和任务 ID 不得互换。
3. 点「延迟下一次查询」，待「等待释放」出现 1，再切换项目或「离开项目」，然后释放旧查询。旧响应不得覆盖当前项目；当前请求应继续独立运行。
4. 完成视频后读取快照：内存项目和持久化项目均应持有对应 `storageKey`；稍后再次读取可观察项目现有延迟写入完成。错误诊断不得出现 `flushSync` 生命周期警告。
5. 点「刷新验收页」后应恢复同一路由与已保存结果。pending 任务会按保存的任务 ID 重建模拟查询，成功结果不应再下载。
6. 点「打开不存在项目」应跳回验收列表占位，不得把上个项目节点写入不存在的项目。点「下次查询失败」可检查失败提示、保留任务 ID以及后续重试。

请求、控制台错误和持久化快照可在工具栏的诊断区域读取。页面不清空整个数据库；再次创建会新增一对专用验收项目。

## 视频工作台

入口：`/tests/browser/video-lifecycle.html`。使用其顶部按钮验收工作台卸载、重挂载、迟到创建响应、查询失败和日志持久化。该页面同样只证明前端生命周期行为，不能证明模型支持边界或生成质量。

1. 开始任务后点产品的「新建」并输入另一条草稿，再完成模拟任务：旧记录成功，当前草稿和空结果保持。
2. 点「下次查询失败」后开始；失败卡片点「重试」，创建次数应不增加。
3. 开启延迟创建后开始任务，离开工作台、释放创建响应、完成模拟任务，再返回：保存并查询原 taskId，只下载一次。
4. 将成功结果加入我的资产，删除对应日志，读取快照：日志消失，但资产和其 media key 保留。删除 pending 日志后完成模拟任务：日志不得复活。
5. 先选 1080p，再通过实际上传按钮导入两张测试图。1080p 置灰但原值保留；开始生成时报错，创建计数不增加，两张参考图仍在。
6. 切换明暗主题核对原控件布局；诊断快照只用于检查本 origin 的测试记录。
